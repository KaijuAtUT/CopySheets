# CopySheets

## これはなに

スプシのテンプレシートをコピーして、各シート固有の情報を変更する GAS コード。  
スプレッドシートを用いた日程調整のために、各人の予定を入れるシートを作るのを効率化しようと思い書いたコードです。

## できること

* スプシのテンプレシートをコピーして、 Info シートをもとに各シート固有の情報を反映する
* 新規作成したシートのリンクを Info シートに貼り付ける

## 使い方

1. スプレッドシートを作成する
    1. ここでは、Info シート B 列 9 行目から No.、名前 の一覧が作成されていることを想定しています
2. GAS のスプレッドシートの URL や、行・列をよしなに変更する
4. 実行する

## デフォルトの設定

* スプシの列は B 列 9 行目から No.、名前 を想定しています
